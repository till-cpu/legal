# Legal pages

Public policy pages for the Spearo spearfishing app, served by GitHub Pages.

| Page | URL |
|---|---|
| Privacy Policy | `/privacy.html` |
| Terms of Service | `/terms.html` |

These URLs go into the Google Play and App Store listings, so **treat them as
permanent** — edit the page contents rather than moving or renaming the files.
The repository is named neutrally for the same reason: the app name can change
without breaking the links.

The source of truth for the wording is `legal/privacy.md` and `legal/terms.md`
in the app repository. Edit there, then mirror the change here.

Nothing here is legal advice. Governing law is not yet stated in the terms.
